# Instruções do projeto

## Commits

Usar o formato de [Conventional Commits](https://www.conventionalcommits.org/)
em todos os commits deste repositório:

```
<tipo>: <descrição curta no imperativo>
```

Tipos mais comuns: `feat`, `fix`, `refactor`, `test`, `docs`, `chore`.

Exemplos:
- `feat: adicionar busca semântica sobre sinopses`
- `fix: corrigir falso positivo do guardrail no REPLACE()`
- `test: cobrir escalonamento de modelo por falha`
- `docs: atualizar passo-a-passo do README`

## Git / GitHub

Nunca dar `git push` (incluindo o primeiro push de um repositório novo) sem
confirmação explícita do usuário antes, mesmo que um repositório remoto já
tenha sido informado anteriormente na conversa.
